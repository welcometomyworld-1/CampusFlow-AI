# APEX TECHNICAL UNIVERSITY
## Department of Computer Science & Engineering
### Course Syllabus: Database Management Systems (CS501)
**Semester:** Fall 2026 (Semester 5) | **Credits:** 4 | **Faculty:** Dr. Sarah Jenkins

---

### Module 1: Relational Model and Relational Algebra
- ER Modeling, Enhanced ER concepts, Relational Data Model
- Relational integrity constraints (Entity, Referential, Domain)
- Relational Algebra operations: Selection, Projection, Joins, Set operations

### Module 2: Advanced SQL & Schema Definition
- DDL, DML, DCL commands
- Complex queries, Subqueries, Correlated subqueries, Window functions
- Views, Triggers, Assertions, Stored procedures

### Module 3: Relational Database Design and Normalization [HIGH EXAM WEIGHTAGE]
- Pitfalls in relational design, Functional Dependencies (FDs)
- Closure of attribute sets, Canonical cover, Lossless join decomposition, Dependency preservation
- Normal Forms: First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF)
- Boyce-Codd Normal Form (BCNF), Multi-valued dependencies and 4NF
- Key Exam Focus: Identifying minimal keys and decomposing schemas into BCNF/3NF without data loss.

### Module 4: Transaction Processing and Concurrency Control [HIGH EXAM WEIGHTAGE]
- Concept of Transaction, ACID Properties, Transaction states
- Concurrent execution anomalies: Dirty read, Non-repeatable read, Phantom read
- Serializability: Conflict serializability, View serializability, Precedence graphs
- Lock-based protocols: Strict Two-Phase Locking (2PL), Rigorous 2PL, Lock conversion
- Deadlock handling: Wait-for graphs, Deadlock prevention (Wait-Die, Wound-Wait)
- Timestamp-based protocols and Optimistic concurrency control

### Module 5: Storage, Indexing, and Query Optimization [HIGH EXAM WEIGHTAGE]
- File organization, Ordered indices, Primary vs. Secondary index, Dense vs. Sparse index
- B-Trees and B+ Trees: Search, Insertion, Deletion algorithms
- Hash-based indexing: Static hashing, Extendible hashing
- Query evaluation plans, Cost-based optimization overview
